# Hybrid Credit Card Fraud Detection with Risk Scoring, SHAP, FastAPI, Streamlit and Power BI

A production-style fraud detection system: a hybrid ML pipeline turns each transaction into a **0-100 risk score** and an
**APPROVE / VERIFY / BLOCK** decision, explains it with **SHAP**, serves it through a **FastAPI** microservice with an audit log,
shows it live in **Streamlit**, and reports on fraud trends, model quality and money saved in **Power BI**.

> Screenshots: add images to `docs/images/` and link them here (Streamlit decision screen, Power BI overview, SHAP summary).

## Highlights
**Data is synthetic:** generated by src/generate_data.py (10 weighted fraud rules).
- **Imbalance handled without SMOTE:** 0.12% fraud (239 / 200,000) → XGBoost `scale_pos_weight`.
- **Hybrid detection:** XGBoost (known fraud) + Isolation Forest + Autoencoder (novel anomalies) + business rules.
- **Cost-sensitive:** thresholds tuned on a validation set to minimise `FN×₹5000 + FP×₹200`, reported on a held-out test set.
- **Explainable (SHAP):** human-readable reasons for every decision.
- **Stateless API design:** `user_profiles.csv` and `last_txn_cache.pkl` give O(1) history lookup per request; Pydantic validation; models loaded once with `lifespan`; sync endpoint so inference runs in the thread pool.
- **Compliance:** every decision appended to a rotating JSONL audit log.
- **Power BI analytics:** star schema, DAX measures, 4-page dashboard (executive, patterns, model & cost, investigation).


## Architecture
```
CSV → features → XGBoost + IsolationForest + Autoencoder + rules → hybrid score → decision
                                   │                                      │
                          FastAPI /score_transaction ─► Streamlit      Power BI star schema
                                   └─► logs/fraud_audit.jsonl
```

## Quick start
```bash
python -m venv .venv && source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python -m src.train                    # trains models → artifacts/
python -m pytest -q tests              # 7 tests
uvicorn api.app:app --reload           # terminal 1 → http://127.0.0.1:8000/docs
streamlit run dashboard/streamlit_app.py   # terminal 2
python -m src.export_powerbi           # data for Power BI → powerbi/data/
```
Use Python 3.10–3.12. Run everything from the repo root. Full walkthrough: [`docs/BUILD_STEPS.md`](docs/BUILD_STEPS.md).
Power BI build steps and DAX: [`powerbi/POWERBI_GUIDE.md`](powerbi/POWERBI_GUIDE.md).

## Results (held-out test set: 40,000 transactions, 48 frauds)
| Strategy | Frauds caught | False alerts | Total cost |
|---|---|---|---|
| Rules only | 48 / 48 | 2,425 | ₹485,000 |
| XGBoost only | 48 / 48 | 115 | ₹23,000 |
| **Hybrid** | 48 / 48 | 114 | **₹22,800** |

ROC-AUC: XGBoost 0.999, hybrid 0.999. Data is synthetic and relatively easy to separate; the hybrid's main benefit is robustness to
unseen fraud patterns, which this dataset cannot fully demonstrate. Exact figures are written to `artifacts/metrics.json` on each run.
